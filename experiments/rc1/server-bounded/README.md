# Bounded Server Track

The public fixture and exact commands are intentionally absent until the sealed handoff is accepted.

Acceptance requires a two-module explicit execution path through native loopback HTTP/1.1, schema-driven canonical JSON, and a parameterized SQLite transaction/query, with a path-free report and fail-closed drift checks. It does not establish TLS, authentication, production databases, pooling, migrations, general scheduling, or an SLA.
