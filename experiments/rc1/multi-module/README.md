# Multi-Module Track

The public fixture is intentionally absent until the sealed handoff supplies the exact non-implementation project inputs used by the measured candidate.

Acceptance requires project, module set, source digests, interface/contract digests, build, per-module translation, explicit execution plan, input, outcome, and report self-digest to remain bound. A single-file demo cannot satisfy this track.

中文：密封交接返回与实测候选完全一致的公开项目输入前，不预造 fixture。验收必须绑定项目、模块集、源码、接口/契约、构建、逐模块翻译、显式计划、输入、结果与报告自摘要。
