# Runtime Distribution / 运行时发行

RC executables are published through GitHub Releases. The launcher verifies the
archive and executable before dispatching the measured native target.
`v1.0.0-rc.1` publishes only Darwin arm64; other targets are intentionally
pending.
RC 可执行文件通过 GitHub Releases 发布。启动器会在分派已实测原生目标前校验归档与可执行文件。
`v1.0.0-rc.1` 只发布 Darwin arm64；其他目标有意保持 pending。
