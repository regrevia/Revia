# Revia V1 RC1 Milestone Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Publish a source-closed, deeply testable `v1.0.0-rc.1` prerelease for genuine macOS arm64 native execution while preserving every existing preview release and explicitly marking the other five targets as pending.

**Architecture:** The private `Re` repository remains the implementation and build authority. A new WP-300 release bridge binds the native CLI to the RC version, produces a deterministic candidate directory, and exports only path-free manifests, hashes, bounded conformance summaries, and the licensed binary package. The public `Revia` repository accepts that export through an exact-file/hash verifier, hosts the deep-trial corpus and public evidence, and publishes the single measured asset through a Darwin-only token-separated gate. Existing preview workflows and tags remain intact.

**Tech Stack:** Rust 2024 native workspace, Node.js 22 private release tooling/tests, POSIX shell public verification, GitHub Actions, `tar`, SHA-256, GitHub CLI.
