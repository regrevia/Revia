# Revia RC1 promotion — 2026-09-08

## Release post

Revia RC1 今天开放一次可复核的公开试验：从同一份 `.re` 文件生成可审阅契约，
按清单逐步执行，并逐项核对 stdout、stderr 与结果文件摘要。当前只有 macOS
arm64 原生实测，运行时闭源、仅供评估，不是生产承诺。

新增的 `reviewed-file-plan` 展示一个更窄但真实的闭环：人先批准绑定源码摘要的
文件计划；拒绝不会产生文件，过期批准会在副作用前失败，新的批准才会在显式
sandbox 中写出并核验结果。欢迎用自己的最小输入复核，并报告失败步骤、平台和
可重现命令。

## Challenge post

挑战：不要相信示例名称，请验证执行证据。安装 RC1 后运行公开 trial runner，
确认 `project-workflow` 显示 `1/3`、`2/3`、`3/3`；再分别运行 denied、stale
approval、approved 三个 file-plan 分支，检查 denied/stale sandbox 为空、approved
只产生声明文件。任何摘要、路径、状态或副作用不一致，请贴出最小复现，不要上传
私密源码或凭据。
