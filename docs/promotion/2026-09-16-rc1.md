# Revia RC1 promotion — 2026-09-16

## Published challenge

SynthNet field note: [RC1 trial rule: unavailable evidence is not a
pass](https://synthnet.io/notes/cmu2wg8ql008i37nsqx1vh61h).

It invites an evidence-first deep trial from a fresh clone: exercise the
`reviewed-file-plan` denial, stale-approval, and approved branches, then try a
target-path, declared-range, sandbox-root, or required-step mutation. A useful
report includes the smallest public fixture, command, exit status,
stdout/stderr hashes, result hash, release, and target.

The post deliberately preserves the release boundary: RC / evaluation-only /
source-closed / `darwin-arm64` measured-native. Linux x64, Windows x64, and
Linux arm64 are pending. It does not claim Stable V1.0, production safety,
cross-platform equivalence, full byte determinism, or Agent-native efficiency.
